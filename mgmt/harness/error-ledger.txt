#
# Format:  <count> <message>   # why it is not a defect <file:line receipt>
#
# AN ENTRY NEEDS A RECEIPT, NOT A RATIONALE. The first version of this file was written in one batch
# by pattern-matching plausible explanations onto 18 messages without reading one line of the code
# that emits them. Jev scored the hiding risk 0.65 for exactly that, and reading the code showed the
# largest entry was WRONG: "inverted DWM bounds - rejecting" at x102 was dispositioned as correct
# handling that is merely over-logged, but agent/gui-agent/main.c:1583 logs it at WARNING precisely
# because it is NOT the routine case - the routine one logs at Debug on line 1537 and falls back to
# GetWindowRect, while this one returns ERROR_INVALID_DATA and the window is REJECTED. x102 is 102
# windows not rendered. It is out of this file and it blocks.
#
# So: no entry without a file:line that shows the condition handled. Everything else stays
# unaccounted and surfaces every run until somebody reads it. That is not a backlog of noise - as of
# 2026-10-14 it is 23 distinct declared error messages in our own logs that nobody has investigated.
#
# A row whose reason is a TODO accounts for nothing. Nothing is hidden either way: accounted
# messages are printed with their reason on every run, and a count that rises past a scaled
# threshold re-surfaces the message even with a reason on file.
#
# CLASSIFICATION IS JEV'S, NOT A HAND CALL (this project's standing rule). tools/classify-errors.sh
# puts the LOGGED LINE and the EMITTING CODE in front of Jev and asks what the line is: handled,
# defect, overlogged, or undecided. The receipt below is that verdict with its distribution, so a
# reader can see how close the call was instead of reading my prose about it.
#
# THE POLICY, stated so it is auditable: a message is accounted for only when defect <= 0.20 AND
# handled+overlogged >= 0.70. Anything else keeps surfacing. An "undecided" is never an account -
# it means the code did not answer, which is a reason to read more, not to stop reporting.
