- **THE READER MUST MATCH THE SECTION'S ABI, AND THAT IS NOT SELF-ENFORCING.** `guest/wgcbroker-peek.ps1` asserted the section's `AbiVersion` against its own constant from the day it was written - and the assertion could never fire, because it was spelled `$ABI` (the constant) against `$abi` (the value read), and PowerShell variable names are CASE-INSENSITIVE: one variable, compared with itself. - **MEASURING A RELAY CHANNEL: three things the instrument must do, each learned from a false verdict on 2026-09-27.** (1) **Identify the driven slot by HWND equality** against the agent's own `AddWindow:` map - not by class (instances accumulate), not by list position, not by published colour count. A selector that reads the wrong number of whitespace fields silently matches nothing, and a present slot then reads as "this window has no capture channel": that produced a "control FAILED" which was pure instrument. The selector now has a fixture selftest that is driven to FAIL on exactly that bug. (2) **A grading function must return ONLY its verdict on stdout.** With `log()` writing to stdout, `R=$(cell ...)` captured the log chatter into the verdict, `case "$R" in PASS*)` never matched, and three cold boots that all delivered printed "0 pass, 0 fail, 0 skip". (3) **Read the frame's AGE from the guest's own clock** - `BrokerHeartbeat - CaptureTick`, both `GetTickCount64`, the heartbeat bumped every broker pass (~250 ms) and `CaptureTick` set at publish. This is the only way to tell "the channel never delivered" from "its frame landed later than my wait", and the two call for completely different work: a cold-boot frame measured 22 s old at the reading, where the census that reported the defect re-read 6 s after the change. `tools/frame-age.py` computes it from any saved `routes.txt`.
